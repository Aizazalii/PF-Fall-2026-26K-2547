Why Use Pull Requests?
Prevent conflicts: Separate branches isolate changes so developers do not overwrite each other's work.
Allow code review: Team members check and test code before it joins the main project. 
Keep main stable: Automated checks and reviews stop bugs from breaking the primary codebase.
Work together safely: Multiple people can code at the same time without crashing the system or blocking others.
